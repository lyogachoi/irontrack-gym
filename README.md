# IronTrack

Мобильный дневник тренировок для тренажёрного зала.

## Возможности

- запись веса, повторений и выполненных подходов;
- таймер тренировки и отдыха;
- история и график тренировочного объёма;
- офлайн-режим и установка на главный экран;
- локальная резервная копия;
- защищённая серверная синхронизация.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

## Сборка

```bash
pnpm build
pnpm build:worker
```

Проект использует Next.js и OpenNext для Cloudflare Workers. Постоянное
хранилище реализовано через Durable Object.
